# BERN02_Exercise-3
This repository contains the code for LOESS regression on air pollution/mortality data from McDonald, G.C. and Schwing, R.C. (1973).

Data Source & Attribution: The dataset used in this project is sourced from:
McDonald, G.C. and Schwing, R.C. (1973). Instabilities of Regression Estimates Relating Air Pollution and Mortality. Technometrics, 15(3), 463–481.
