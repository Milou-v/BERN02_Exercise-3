# BERN02_Exercise-3
This repository contains the code for LOESS regression on air pollution/mortality data from McDonald and Schwing (1973).

Key components in this repository:
* `Exercise_3_copy1.ipynb` - Primary analysis notebook containing data importing, model build and visualisation.
* `pollution_cleaneddata.csv` - Cleaned data from McDonald and Schwing (1973).
* `pollution_metadata.txt` - Metadata provided by McDonald and Schwing (1973) on the air pollution dataset. 
* `environment.yml` - Conda environment specifications for reproducing the runtime setup.

Data Source & Attribution: The dataset used in this project is sourced from:
McDonald, G.C. and Schwing, R.C. (1973). Instabilities of Regression Estimates Relating Air Pollution and Mortality. Technometrics, 15(3), 463–481.
